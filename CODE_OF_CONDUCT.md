# Código de Conducta

## Nuestro Compromiso (Our Pledge)
Nos comprometemos a hacer de la participación en este proyecto una experiencia libre de acoso para todos.

## Nuestros Estándares (Our Standards)
Los comportamientos que contribuyen a un ambiente positivo incluyen el respeto mutuo, la crítica constructiva y la empatía.

## Responsabilidades de Aplicación (Enforcement Responsibilities)
Los mantenedores del proyecto son responsables de aclarar y hacer cumplir estos estándares.

## Alcance (Scope)
Este Código de Conducta aplica dentro de todos los espacios del proyecto y en espacios públicos cuando un individuo representa al proyecto.

## Aplicación (Enforcement)
Los casos de comportamiento abusivo pueden reportarse contactando al equipo del proyecto.

## Directrices de Aplicación (Enforcement Guidelines)
Los mantenedores seguirán estas pautas para determinar las consecuencias de cualquier violación a este Código de Conducta.

## Atribución (Attribution)
Este Código de Conducta está adaptado del Contributor Covenant, versión 2.1.
