# Simple Interest Calculator

## Descripción
Este proyecto es una calculadora de interés simple desarrollada en Bash. 
Permite calcular el interés simple a partir de tres valores ingresados por el usuario: 
capital (principal), tasa de interés (rate) y período de tiempo (time).

## Fórmula utilizada
Interés Simple = (Capital × Tasa × Tiempo) / 100

## Cómo usar
1. Clona el repositorio.
2. Ejecuta el script `simple-interest.sh` en tu terminal.
3. Ingresa los valores solicitados: capital, tasa de interés y tiempo.
4. El script mostrará el interés simple calculado.

## Ejemplo
```bash
$ bash simple-interest.sh
Enter principal amount: 1000
Enter interest rate: 5
Enter time period: 2
Simple Interest: 100
```
